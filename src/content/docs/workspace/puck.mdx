Puck 是你的个人 Amp 助理，帮你管理 Amp 里的一切：启动 agent、监控它们、给它们发消息、创建项目等等。

## 打开方式

- ampcode.com：按 `Ctrl`+`/` 打开或关闭，Puck 在侧边栏取代线程列表
- TUI：`Ctrl`+`O` 打开命令面板选 `puck: open`，或按 `Ctrl`+`X` 再按 `P`
- iOS / Android：打开侧边栏点 **Puck**
- macOS：Puck 侧边栏菜单里的 **Open in Separate Window** 可开独立窗口

## 能做什么

- **启动与指挥 agent** — 「在 ampcode/amp 启动一个 agent，查一下 CI 为什么挂了」
- **查找与管理线程** — 找之前的对话、查看活跃线程、归档完成的工作
- **发送保存的提示** — 内置 `ship`、`update-base`、`refactor-commits`、`review`，也可在 Prompts 页添加自己的
- **操作项目** — 找项目、建项目、用正确的仓库和环境启动 agent
- **协调并行工作** — 把一个请求拆给多个 agent，再汇总它们的报告
- **使用技能** — Puck 会加载你的个人与工作区 skills（但它没有 orb，不能运行脚本，也不加载插件）
- **使用已连接的服务** — 例如查看 GitHub checks 或在 Slack 中搜索上下文

## 语音通话

点击 Puck 输入框旁的 **Call Puck**，或按 `Ctrl`+`Shift`+`/`。在 **Settings > Puck** 的 **Voice Call Instructions** 中可写只对语音通话生效的指示，例如「我一直用中文回答」。

## 速度

Puck 默认 Standard 速度。想要更快，在 **Settings > Puck** 中选择 **Fast** 或 **Plaid**；越快越贵，菜单会显示价格。

## 在其它应用里使用 Puck

可以从 Claude、ChatGPT 等 MCP 客户端与同一个 Puck 对话。在 **Settings > Puck** 的 **Puck in Other Apps** 中：Claude 点 **Add to Claude**；其它 MCP 客户端添加远程 MCP 服务器 `https://ampcode.com/mcp`。该服务器提供三个工具：`puck`、`new_puck_conversation` 和 `orbs`。
