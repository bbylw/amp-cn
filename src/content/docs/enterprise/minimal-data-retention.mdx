最小数据保留（MDR）对所有 Amp 用户开放，前提是请求经由 Amp 管理的模型供应商连接并使用 Amp 积分。它限制第三方模型供应商保留提示与回复的时长，但**不**意味着完全不保留数据。

在 MDR 下，供应商只在返回响应所需的时间内保留普通提示与响应。例外情况：

- 供应商可以保留安全与滥用监控数据，包括分类器结果、信任与安全评分、被标记为可能违反使用政策的内容，按其滥用预防与安全政策保留
- 某些模型或功能需要更长保留期，供应商可在其当前文档中说明并最多保留 30 天
- 供应商可以短期存储由提示派生的计算产物（如 KV 张量、缓存 token）；这种情况下生成响应后不保留原始提示文本
- 法律、法院命令或监管要求时，供应商可以保留数据

Amp 与模型供应商都不会用客户数据训练模型，除非你明确选择加入训练；企业版工作区永远无法开启训练。随着供应商服务与数据处理条款变化，模型/功能的 MDR 资格可能改变，部分模型与功能不适用 MDR，Amp 会在你启用时标注。

MDR 只覆盖推理过程中第三方供应商处理的数据，不控制 Amp 如何存储线程数据（见 Amp 的线程数据规则）。使用客户自管的模型供应商连接（例如自己的 API key）时，适用你与该供应商账号之间的保留条款。
