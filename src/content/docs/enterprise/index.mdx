企业版为定制价格，并额外提供控制与支持：

- SCIM 目录同步、管理员控制
- [最小数据保留](/enterprise/minimal-data-retention)
- 高级线程可见性控制、按用户成本控制
- MCP registry 白名单、集中管理的用户设置
- 阻止成员使用个人 Model Routing 的控制
- 用于成本归属的用户组，以及按组的线程可见性选项（按需）
- 可配置的线程保留期（按需）
- 工作区访问 IP 白名单（按需，额外收费）
- 自带 Key 模型供应商的区域端点支持

安全特性详见 [Amp Security Reference](https://ampcode.com/security)。要开始使用企业版，[联系 Amp 团队](https://ampcode.com/contact-sales)。
