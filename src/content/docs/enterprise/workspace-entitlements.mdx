[Amp 企业版](/pricing)工作区可以通过 entitlement 给每个用户设用量配额，例如：

- 普通成员每周 $50、高级工程师每周 $200
- 所有成员每人每天 $100
- 外包与全职员工用不同上限

在工作区设置的 **Entitlements** 区域配置。

## 成员看到什么

成员可以在个人设置里看到自己的配额与剩余用量。例如"每周工作区配额，剩余 75%，$150 中剩 $112.50"。

## 指派方式

- **Default** — 设为默认的配额，作用于所有没有被更具体指派的成员
- **Individual** — 直接指派给特定成员
- **Workspace Group** — 指派给 Amp 工作区分组；当前成员获得配额，成员变化会自动更新覆盖范围
- **Directory Group** — 关联到通过 SCIM 从身份提供方（Okta、Entra ID 等）同步过来的目录分组，组内成员自动获得

## 解析顺序

同时满足多个配额时：

1. Individual
2. Workspace Group
3. Directory Group
4. Default

同一优先级下有多个时，取折算后日配额最高的那个。

Amp 按当前生效的配额检查花费，用量按用户和配额分别统计。改同一个配额的设置，历史用量仍挂在它上面；用户生效配额变了，之前另一份配额的花费不计入新配额。走自带模型供应商（BYOK）的请求按推理的标价估算，也计入配额。通过订阅（ChatGPT、Claude 订阅）走的推理**不**计入，因为订阅是预付的，你不按标价付费。
