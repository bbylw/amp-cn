Amp 从 `AGENTS.md` 文件中读取代码库结构、构建/测试命令和编码规范。

| 文件位置 | 典型内容 |
| --- | --- |
| 当前目录、父目录及子树的 `AGENTS.md` | 架构、构建/测试命令、内部 API 概览、审查与发布步骤 |
| `$HOME/.config/amp/AGENTS.md` `$HOME/.config/AGENTS.md` | 个人偏好、设备特定命令，以及提交进仓库前本地试验的指导 |
| `/etc/ampcode/AGENTS.md` `/Library/Application Support/ampcode/AGENTS.md` `%ProgramData%\ampcode\AGENTS.md` | 系统级或组织统一管理的指导 |

## 加载规则

- 当前工作目录（或编辑器工作区根）**以及父目录**（直到 `$HOME`）里的 `AGENTS.md` 始终包含
- 子树的 `AGENTS.md` 在 agent 读取该子树中的文件时包含
- 系统级文件以及两个 `$HOME/.config` 下的文件若存在，始终包含
- 如果目录里没有 `AGENTS.md`，但有 `AGENT.md`（少个 S）或 `CLAUDE.md`，则包含后者
- 工作区管理员提供的 Global AGENTS.md 在个人与仓库指导之前包含，但不作用于子 agent、Puck 和自定义 agent

## 文件引用

在 AGENTS.md 中用 @ 引用其它文件作为上下文：

```bash
参见 @doc/style.md 和 @specs/**/*.md

提交时参考 @doc/git-commit-instructions.md
```

- 相对路径相对于包含该引用的 agent 文件解析
- `@~/some/path` 指向你的主目录；不支持绝对路径
- 代码块中的 @ 引用会被忽略，避免误判
- 支持 glob，例如 `@doc/*.md`、`@.agent/**/*.md`

## 条件生效（globs）

在被引用的文件里用 YAML front matter 的 `globs`，让规则只在处理特定文件时生效：

```bash
---
globs:
  - '**/*.ts'
  - '**/*.tsx'
---

遵循以下 TypeScript 规范：

- 永远不使用 `any` 类型
- ...
```

只有 Amp 读过匹配任一 glob 的文件时，该文件才会被包含；没有 `globs` 的文件每次被 @ 引用都会包含。glob 默认隐式加上 `**/` 前缀，若以 `../` 或 `./` 开头则相对于被引用的文件。

## 忽略指导文件

设置环境变量 `AMP_IGNORE_GUIDANCE_FILES`（用 `:` 分隔的 glob 列表）可跳过匹配的指导文件，匹配的是绝对路径。例如在不改变 `$HOME` 的情况下跳过个人指导：

```bash
AMP_IGNORE_GUIDANCE_FILES="$HOME/.config/amp/AGENTS.md:$HOME/.config/AGENTS.md" amp -x "do the thing"
```

`AMP_IGNORE_GUIDANCE_FILES='*'` 会忽略所有指导文件，Amp 不再自动加载任何 `AGENTS.md`。
