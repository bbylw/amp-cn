## 三步开始

1. **登录** — 打开 [ampcode.com](https://ampcode.com) 注册并登录。Orb 跑在 Amp 云端，无需安装任何东西
2. **添加代码** — 用 Git 仓库创建一个[项目](/workspace)，或者以「No Project」开始
3. **在 Orb 中运行 agent** — 在新线程对话框里把执行位置设为 **New Orb**，选好项目，描述你想要的结果

:::note
agent 拥有一整台机器，所以可以直接安装依赖、启动应用、开浏览器做端到端验证。让它先证明改动可用，再交给你看。
:::

## 安装 CLI

```bash
curl -fsSL https://ampcode.com/install.sh | bash
```

安装后运行 `amp` 进入交互模式。首次运行会提示登录。

也支持 Homebrew 与 npm（macOS / Linux / WSL；Windows 请使用 WSL）。

## 安装应用

| 平台 | 要求 |
| --- | --- |
| macOS | Apple 芯片，macOS 26 及以上 |
| iPhone / iPad | iOS / iPadOS 26 及以上（TestFlight 测试版） |
| Android | Android 13 及以上（APK） |
| Windows | Windows 10 1809+ 或 Windows 11 |
| Linux | apt / dnf / AUR，x86-64 或 ARM64 |

应用不需要额外安装任何东西，因为 agent 运行在 orb 里，而不是你的设备上。
