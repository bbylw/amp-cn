Amp 是为前沿模型打造的编程 agent 与开发环境。它不再只是终端里的一个工具，而是一套贯穿网页、桌面、手机和 CLI 的工作方式。

- **🧠 多模型** — GPT-5.6、Claude Fable 5.1、快速模型……Amp 会为每类工作挑最合适的模型
- **☁️ Orbs** — Amp 为每个线程创建的机器，代码、工具和插件都已就绪。发出提示、合上笔记本，agent 继续干活
- **📱 无处不在** — 在 iPhone 上发起，在 Mac 上查看，在 TUI 里继续。线程就绪时应用会通知你
- **🎯 固执己见** — 你始终用到 Amp 最好的部分。我们自己不用、不爱用的功能，会被砍掉
- **⚡ 站在前沿** — 模型走到哪，Amp 跟到哪。没有向后兼容，没有历史包袱
- **🧵 线程** — 与 Amp 的每次交互都可保存、跨设备继续、分享给同事

## 在哪儿用

- **网页** — 打开 [ampcode.com](https://ampcode.com)，无需安装。发起线程后 Amp 会在 [orb](/orbs) 中工作
- **Mac / iPhone / iPad / Android / Windows / Linux** — [原生应用](/apps)提供听写、跨应用分享和通知
- **终端** — [CLI](/cli) 可在你自己的机器、编辑器终端或脚本中运行 Amp
- **Puck** — 帮你启动和协调 agent 的个人助理，见 [Puck](/workspace/puck)
