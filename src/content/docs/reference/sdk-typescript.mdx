`@ampcode/sdk` 的 API 参考。

## 安装

```bash
npm install @ampcode/sdk
npx -y @ampcode/sdk install   # 可选：手动安装 Amp CLI（已是依赖）
```

需要 Amp Neo 之前的版本时：`npm install @ampcode/sdk@0.1.0-20260528044221-ge0e19fa`。

## 函数

### execute()

程序化执行 Amp CLI 命令的主函数。

```ts
function execute(options: ExecuteOptions): AsyncIterable<StreamMessage>
```

**参数**

- `options`（`ExecuteOptions`）—— 执行配置

**返回**

- `AsyncIterable<StreamMessage>` —— 来自 Amp CLI 的消息流

```ts
import { execute } from '@ampcode/sdk'

for await (const message of execute({
  prompt: 'Analyze this codebase',
  options: { cwd: './my-project' },
})) {
  if (message.type === 'assistant') {
    console.log('Assistant:', message.message.content)
  } else if (message.type === 'result' && !message.is_error) {
    console.log('Final result:', message.result)
    break
  }
}
```

### createUserMessage()

构造流式对话用的用户输入消息。

```ts
function createUserMessage(text: string, options?: { requestId?: string }): UserInputMessage
```

- `text`（`string`）—— 消息文本
- `options.requestId`（`string`，可选）—— 1–256 字符的 ID；在同一线程上重试时复用可避免重复创建用户消息

```ts
import { createUserMessage } from '@ampcode/sdk'

const message = createUserMessage('Analyze this code', { requestId: 'analysis-123' })
// { type: 'user', requestId: 'analysis-123', message: { role: 'user', content: [{ type: 'text', text: 'Analyze this code' }] } }
```

### threads.new()

创建一条新的空线程并返回 ID。

```ts
async function threads.new(options?: ThreadsNewOptions): Promise<string>
```

```ts
import { threads } from '@ampcode/sdk'

const threadId = await threads.new({ visibility: 'private' })
```

### threads.markdown()

把线程渲染成 markdown。

```ts
async function threads.markdown(options: ThreadsMarkdownOptions): Promise<string>
```

```ts
const markdown = await threads.markdown({ threadId: 'T-abc123-def456' })
```

### threads.setMultiplayer()

打开或关闭 multiplayer。只对在 orb 或共享 runner 上运行的共享线程的所有者有效。

```ts
async function threads.setMultiplayer(options: ThreadsSetMultiplayerOptions): Promise<void>
```

```ts
await threads.setMultiplayer({ threadId: 'T-abc123-def456' })                // 默认时长（目前一周）
await threads.setMultiplayer({ threadId: 'T-abc123-def456', hours: 12 })    // 12 小时
await threads.setMultiplayer({ threadId: 'T-abc123-def456', enabled: false }) // 关闭
```

## 类型

### ExecuteOptions

```ts
type ExecuteOptions = {
  prompt: string | AsyncIterable<UserInputMessage>
  options?: AmpOptions
}
```

### AmpOptions

字段与 [Python SDK 的 `AmpOptions`](/reference/sdk-python#ampoptions) 一一对应，TypeScript 里用 camelCase：

| 字段 | 说明 |
| --- | --- |
| `cwd` | 本地 CLI 子进程的工作目录 |
| `mode` | 内置模式 `low` / `medium` / `high` / `ultra`，也接受插件定义的模式名 |
| `model` | 以 `provider/name` 指定模型（如 `openai/gpt-6-astra`），与 `mode` 二选一 |
| `effort` | `none` / `minimal` / `low` / `medium` / `high` / `xhigh` / `max`，配合 `model` |
| `noArchiveAfterExecute` | 执行结束后不归档新线程 |
| `visibility` | `private` / `unlisted` / `workspace` / `group`，默认 `workspace` |
| `settingsFile` | 自定义设置文件路径 |
| `logLevel` / `logFile` | `debug` / `info` / `warn` / `error` / `audit`，以及日志文件 |
| `env` | 传给 CLI 的环境变量 |
| `continueThread` | `true`、`false` 或线程 ID |
| `mcpConfig` | MCP 配置对象或文件路径 |
| `skills` | 技能目录 |
| `enabledTools` | 只启用列出的工具 |
| `labels` | 线程标签 |
| `thinking` | 输出思考块 |
| `executor` | `local` / `orb` / `runner` |
| `runnerId` / `runnerDir` | runner 执行时的 runner 与目录（绝对路径） |
| `project` | 仅 orb 执行时可用，`namespace/name`、`owner/repo` 或仓库 URL |
| `title` | 线程标题 |

远程执行（`orb` / `runner`）时 `prompt` 必须是字符串，`enabledTools`、`skills`、`mcpConfig` 等本地选项会被忽略并给出警告；插件定义的模式需在 runner 上加载。`cwd` 只决定本地 CLI 子进程目录，不决定 runner 上的目录；每条线程只有一个工作目录，多目录请分别调用 `execute()`。

### StreamMessage

与 [流式 JSON](/cli/streaming-json) 的消息一致：

- `{ type: 'system', subtype: 'init', cwd, session_id, tools, mcp_servers }`
- `{ type: 'user', message, parent_tool_use_id, session_id }`
- `{ type: 'assistant', message, parent_tool_use_id, session_id }`
- `{ type: 'result', subtype, duration_ms, is_error, num_turns, result, session_id }`

### UserInputMessage

```ts
type UserInputMessage = {
  type: 'user'
  requestId?: string
  message: { role: 'user'; content: Array<{ type: 'text'; text: string }> }
}
```
