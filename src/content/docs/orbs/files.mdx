任务从文本和源码之外的东西开始时，把文件附到 orb 线程上。Amp 能处理截图、录屏、音频、PDF、日志、表格、数据集、压缩包等。

## 附加文件

用输入框里的附件按钮、把文件拖进输入框，或从剪贴板粘贴。再补一句说明：文件里是什么、你想要什么结果。

```text
看这段录屏，在应用里复现问题，修掉菜单展开时布局跳动的原因。
```

```text
分析这些日志。把相关错误分组，找出每组里第一个失败，然后告诉我哪个最可能解释这次故障。
```

普通用户单个文件上限 100 MB，额度更高的用户可到 512 MB。

[原生应用](/apps)还多几种方式：iOS 的附件按钮可以直接拍照或录像；macOS、iOS 和 Windows 可以从别的应用的分享面板（Windows 是 **Share**）分享图片，结果会进 [Puck](/workspace/puck)。

想把文件直接放进 orb 的文件系统而不是附在线程上，就拖到 **Files** 面板或粘进终端，见 [上传文件到 Orb](/orbs)。

## Amp 怎么用附件

附件只属于该线程，不会自动复制进仓库。图片、PDF、音频、视频 Amp 能直接读；其它类型在需要本地工具处理时会下载进 orb。原文件必须保持不动、或产出要放到特定目录时，明确告诉它。

## 查看与删除

在线程菜单里选 **Attachments** 可看到随线程保存的所有文件：消息附件，以及 agent 上传的截图、录像。**Public** 徽章表示 Amp 已发布该文件，**Temporary** 表示几小时后过期。有删线程权限的人可以逐个或全部删除。

附件是随线程保存的副本，与 orb 的 **Files** 面板无关：删附件不会改动 orb。

## 常用任务

- 录下应用里的问题，让 Amp 复现并修复
- 附加日志或诊断包做排查
- 把演示文稿、表格变成可交互网页
- 分析 CSV 等数据集并生成报告
- 转写或总结音视频
- 参考素材生成新的图片、视频、文档或模型

## 分享生成的文件

orb 里创建的文件默认留在工作区，除非 Amp 把它附到回复或发布出去。说清你要哪种结果：

```text
把清洗后的行导出成 CSV，附在最终回复里。
```

```text
把做好的演示视频发布出去，方便我在线程外分享。
```

只有当"任何人拿到链接都能看"是安全的，才发布文件；普通线程附件仍受 Amp 的访问检查保护。
