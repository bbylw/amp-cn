Orb 是 Amp 为线程创建的云端沙箱。每个 orb 线程都得到一个全新的隔离环境，里面有你的代码、插件、开发工具，以及创建它的线程的上下文。

## 为什么用 Orb

- **合上笔记本也继续工作** — 代理在 orb 里跑，与你的电脑无关
- **不占本机资源** — 同时开几个互不相干的任务，各自跑多久都行
- **不用管机器** — 代理干完活，orb 自动休眠，休眠不收费，睡几周也没关系。再发提示时，会话、文件和服务都还在
- **可以要求更完整的结果** — 它有一整台机器，能装依赖、跑应用、开浏览器做端到端验证

## 启动节奏

每个用户可以先连续启动 20 个计费 orb；之后每 5 分钟启动一个新 orb。后续启动会排队等待而不是失败，线程会显示预计等待时间。

## 查看改动与浏览文件

打开线程的 Changes 视图审查 diff；也可以在**不克隆仓库**的情况下浏览并打开 orb 里的任意文件。

## 使用终端

打开 **Terminal** 标签获得 orb 内的 shell。终端与代理使用同一文件系统和工作副本，任何一边的改动另一边立刻可见。它运行在共享的 tmux 会话中，Amp 能读取其输出并操作长时间运行的命令。

## 在任何设备上跟进

因为工作在 orb 而不是你的电脑上，你可以用任意设备查看。macOS、Windows、Linux、iOS、Android 的 [Amp 应用](/workspace/apps)显示与 ampcode.com 相同的线程，并在线程等待你回复时通知你。

## 上传文件到 Orb

- **附加到线程** — 用输入框的附件按钮、拖入或粘贴。代理能看到附件，需要时下载进 orb
- **通过 Files 面板上传** — 把文件拖到 **Files** 标签；拖到目录上就上传到该目录，拖到面板其它位置则上传到仓库根目录。也可以点击工具栏上传按钮，或右键目录选择 **Upload Files…**
- **粘贴或拖进终端** — 粘贴图片或拖入文件，Amp 上传并把绝对路径插入光标处

通过 Files 面板或终端上传的文件每个最大 512 MB。

## 把改动同步到本机

```bash
amp sync <thread>
```

`amp sync` 会把 orb 线程的改动镜像到你的本地检出，同时代理仍在远端工作。需要在一个干净（没有未提交改动）的检出中运行。停止时会重置回原来的状态，所以运行期间不要本地编辑文件。

只想取一次结果，加 `--apply`：检出 orb 所在分支与最新提交、应用未提交的改动后退出，结果留在你的检出里。可用 `--checkout` 免确认切换分支，或 `--skip-checkout` 只应用改动。

从网页复制命令：线程的 More Actions 菜单里选 **Orb → Copy Sync CLI Command**。

## 从 CLI 启动 Orb

```bash
amp -ox "Investigate why the latest CI run on main failed"
```

需要不同算力时用 `--orb-size`：

```bash
amp -ox "Run the performance test matrix" --orb-size a1.large
```

## 从 TUI 启动 Orb

按 `Ctrl`+`O` 打开命令面板，选择 `thread: new in orb`。想先选项目，用 `project: select`；仓库还没有 Amp 项目时用 `project: create`。
