Amp 没有按量付费之外的强制门槛：可以选月度档位拿到更高性价比，也可以按标准费率随用随付。关联 ChatGPT / Claude 订阅还能把对应模型的用量计入订阅。

- **🎁 Hobby（免费）** — 包含全部产品功能；Amp 托管的 orb 按量付费；**自托管 orb 与 runners 免费且不限量**；可用任何来源的 token、自带 Key（BYOK）
- **💳 Individual（$20/月起）** — Megawatt 档含 45,000 分钟 Amp 托管 orb 时长；Gigawatt 更高；自托管 orb 与 runners 仍免费；不限公开/私有仓库；可用自己的域名托管 portals
- **👥 Teams（不额外收费）** — 成员可分属不同档位；团队线程分享、Multiplayer 与权限；共享 portals、插件与技能；用户管理与分析；共享账单与合并积分；SAML/OIDC SSO
- **🏢 Enterprise（定制）** — 含 Individual 与 Teams 全部能力，另有 SCIM、支出限额与报表、审计日志、IP 白名单、区域端点、更高配额与优先支持

登录后还可以选择 **Megawatt 50**（$50/月），包含 2.5 倍于 Megawatt 的 agent 与 orb 用量。

## 用量如何计费

- 档位内含的 agent 用量用完后，可以加购积分继续工作。Amp 按线程中实际的模型与工具用量扣费；对个人和非企业工作区**不加价**（即直接透传供应商 API 价格）
- 付费积分无需订阅或承诺。网页搜索等非模型工具也消耗积分
- 示例：某线程用了 $2 的 Anthropic API 和 $0.50 的 OpenAI API，Amp 从积分中扣 $2.50
- Orb 使用单独的额度，按分钟计费，暂停不收费
- 积分可在用户设置、工作区设置中购买和查看，或运行 `amp usage`。购买的积分自购买起 12 个月后过期；工作区成员共享工作区积分

:::note
想看某个线程的详细花费，点击线程页右侧的 `$` 价格；也可以直接问 Amp 解释你的用量。
:::
